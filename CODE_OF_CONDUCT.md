# Code of conduct

Be constructive, patient, and respectful.

- Discuss ideas and behavior rather than people.
- Welcome questions and corrections made in good faith.
- Do not post private information, credentials, or identifying equipment/location data.
- Avoid harassment, threats, discrimination, and disruptive behavior.
- Respect maintainers' decisions about project scope, safety, and remediation risk.

Project maintainers may edit or remove content and restrict participation when needed to keep the project useful and safe. Report conduct concerns privately through the maintainer's GitHub profile rather than opening a public issue.
